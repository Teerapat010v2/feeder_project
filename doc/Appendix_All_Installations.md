# ภาคผนวก: ขั้นตอนการติดตั้งและตั้งค่าโปรแกรมที่เกี่ยวข้องทั้งหมด

เอกสารฉบับนี้รวบรวมขั้นตอนการติดตั้งโปรแกรมและการตั้งค่าบริการคลาวด์เซอร์วิส (Cloud Services) ทั้งหมดที่ใช้ในโครงงานเครื่องให้อาหารปลาอัตโนมัติ เพื่อเป็นคู่มือสำหรับการนำไปพัฒนาต่อยอดหรือติดตั้งระบบใหม่ตั้งแต่ต้น

---

## 1. การติดตั้ง Visual Studio Code (VS Code) และ PlatformIO

โครงงานนี้ใช้ VS Code ร่วมกับส่วนขยาย PlatformIO ในการพัฒนาเฟิร์มแวร์ของ ESP32 แทนการใช้ Arduino IDE เนื่องจากมีระบบจัดการไลบรารีอัตโนมัติและสามารถจัดการระบบไฟล์ (SPIFFS) ได้ดีกว่า

**ขั้นตอนการติดตั้ง:**
1. ไปที่เว็บไซต์ [https://code.visualstudio.com/](https://code.visualstudio.com/) และดาวน์โหลด VS Code สำหรับ Windows
2. ดำเนินการติดตั้งตามขั้นตอนของโปรแกรม (แนะนำให้เลือก "Add 'Open with Code' action" ในขั้นตอนติดตั้ง)
3. เมื่อเปิด VS Code ให้ไปที่เมนู **Extensions** (หรือกด Ctrl + Shift + X)
4. ค้นหาคำว่า **PlatformIO IDE** และกดปุ่ม **Install**
5. รอจนกว่าระบบจะดาวน์โหลดเครื่องมือเบื้องหลังเสร็จสิ้น (สังเกตสถานะมุมขวาล่าง) จากนั้นให้กด **Reload Window** หรือรีสตาร์ทโปรแกรม VS Code
6. เปิดโฟลเดอร์โปรเจกต์ esp32/fish_feeder ระบบ PlatformIO จะดาวน์โหลดไลบรารีที่จำเป็นใน platformio.ini ให้อัตโนมัติเมื่อกดปุ่ม Build (✓) หรือ Upload (→)

---

## 2. การติดตั้ง Node.js

Node.js เป็นโปรแกรมที่จำเป็นสำหรับการรันเซิร์ฟเวอร์ Backend และใช้สำหรับการจำลองการทำงานบนเครื่องคอมพิวเตอร์ (Localhost)

**ขั้นตอนการติดตั้ง:**
1. ไปที่เว็บไซต์ [https://nodejs.org/](https://nodejs.org/)
2. ดาวน์โหลดเวอร์ชัน **LTS (Long Term Support)**
3. ดำเนินการติดตั้งโปรแกรม โดยสามารถกด Next ตามค่าเริ่มต้นได้จนจบขั้นตอน
4. ตรวจสอบการติดตั้งโดยเปิด Command Prompt หรือ Terminal แล้วพิมพ์คำสั่ง 
ode -v และ 
pm -v ระบบจะแสดงเวอร์ชันที่ติดตั้งสำเร็จ

---

## 3. การสมัครและตั้งค่า GitHub (Source Control)

GitHub เป็นพื้นที่สำหรับจัดเก็บซอร์สโค้ดและเป็นศูนย์กลางในการเชื่อมต่อโค้ดไปยังบริการ Cloud ต่างๆ (เช่น Vercel และ Render)

**ขั้นตอนการตั้งค่า:**
1. สมัครสมาชิกที่ [https://github.com/](https://github.com/)
2. ดาวน์โหลดและติดตั้ง Git จาก [https://git-scm.com/](https://git-scm.com/)
3. ในเว็บไซต์ GitHub ให้คลิกปุ่ม **New** เพื่อสร้าง Repository ใหม่ และตั้งชื่อโปรเจกต์
4. นำโค้ดของโครงงานอัปโหลดขึ้น Repository ผ่านแถบ Source Control ในโปรแกรม VS Code หรือใช้คำสั่ง git push

---

## 4. การตั้งค่าบริการคลาวด์: HiveMQ (MQTT Broker)

HiveMQ ทำหน้าที่เป็นตัวกลาง (Broker) ในการรับส่งข้อความระหว่าง ESP32, หน้าเว็บ และเซิร์ฟเวอร์

**ขั้นตอนการตั้งค่า:**
1. ไปที่ [https://console.hivemq.cloud/](https://console.hivemq.cloud/) สมัครและล็อกอินเข้าสู่ระบบ
2. เลือกใช้งานแพ็กเกจ **Serverless (Free)** ระบบจะสร้าง Cluster ให้อัตโนมัติ
3. เข้าไปที่เมนู **Access Management** เพื่อสร้างผู้ใช้งาน (กำหนด Username และ Password) สำหรับให้อุปกรณ์ต่างๆ ล็อกอิน
4. ในหน้า Overview คัดลอก **Cluster URL** (ตัวอย่าง: xxx.s1.eu.hivemq.cloud)
5. พอร์ตที่ใช้คือ **8883** (สำหรับ ESP32 / Backend) และพอร์ต **8884** (สำหรับ WebSockets บนหน้าเว็บ)

---

## 5. การตั้งค่าฐานข้อมูลคลาวด์: Neon (Serverless PostgreSQL)

Neon เป็นบริการฐานข้อมูล PostgreSQL บนคลาวด์ สำหรับจัดเก็บสถานะอุปกรณ์และประวัติการให้อาหาร

**ขั้นตอนการตั้งค่า:**
1. ไปที่ [https://neon.tech/](https://neon.tech/) และสมัครสมาชิก
2. คลิก **New Project** ตั้งชื่อโปรเจกต์และสร้างฐานข้อมูล
3. เมื่อสร้างเสร็จสิ้น ไปที่หน้า Dashboard และคัดลอก **Connection String** (รูปแบบ postgresql://user:password@endpoint/dbname)
4. นำ Connection String ไปตั้งค่าเป็นตัวแปรแวดล้อม (DATABASE_URL) ในเซิร์ฟเวอร์ Backend (Render)

---

## 6. การเผยแพร่ Backend ด้วย Render

Render เป็นผู้ให้บริการคลาวด์สำหรับการฝากและรัน Backend Server (Node.js)

**ขั้นตอนการตั้งค่า:**
1. ไปที่ [https://render.com/](https://render.com/) และลงชื่อเข้าใช้ด้วย GitHub
2. คลิก **New +** และเลือก **Web Service**
3. เลือกดึงโค้ดจาก Repository ใน GitHub ที่สร้างไว้
4. ตั้งค่าสภาพแวดล้อม: 
   - Build Command: 
pm install
   - Start Command: 
ode server.js (หรือคำสั่งที่ระบุในไฟล์ตั้งค่า)
5. ไปที่เมนู **Environment Variables** เพื่อเพิ่มค่าคงที่ต่างๆ เช่น DATABASE_URL, ข้อมูลล็อกอิน HiveMQ, DEVICE_ID เป็นต้น
6. คลิก **Create Web Service** และรอระบบประมวลผลจนเสร็จสิ้น

---

## 7. การเผยแพร่ Frontend ด้วย Vercel

Vercel เป็นบริการสำหรับฝากและให้บริการหน้าเว็บไซต์ (Frontend) ซึ่งเชื่อมต่อกับ GitHub โดยตรง

**ขั้นตอนการตั้งค่า:**
1. ไปที่ [https://vercel.com/](https://vercel.com/) และลงชื่อเข้าใช้ด้วย GitHub
2. ในหน้า Dashboard คลิก **Add New... > Project**
3. ค้นหา Repository โปรเจกต์ในรายการและคลิก **Import**
4. ในส่วน Framework Preset สามารถปล่อยเป็นค่าเริ่มต้น (Other)
5. หากหน้าเว็บอยู่ในโฟลเดอร์เฉพาะ (เช่น โฟลเดอร์ web) ให้ตั้งค่า Root Directory ให้ถูกต้อง
6. คลิกปุ่ม **Deploy** เพื่อให้ Vercel ดึงโค้ดและเผยแพร่เป็นเว็บไซต์ออนไลน์ (ได้รับ URL เป็น .vercel.app)

## 8. ไลบรารีและโมดูลเสริมที่ใช้งาน (Libraries & Dependencies)

ในการพัฒนาโครงงานนี้ มีการเรียกใช้งานไลบรารีและโมดูลเสริม (Dependencies) ทั้งในส่วนของไมโครคอนโทรลเลอร์ (ESP32) และส่วนของเซิร์ฟเวอร์ (Node.js) ดังนี้

### 8.1 ไลบรารีสำหรับ ESP32 (ติดตั้งผ่าน PlatformIO)
ไลบรารีเหล่านี้ถูกกำหนดไว้ในไฟล์ platformio.ini ระบบจะทำการดาวน์โหลดให้อัตโนมัติ:
- **ArduinoJson (โดย Benoit Blanchon):** สำหรับจัดการ แปลง และสร้างข้อมูลในรูปแบบ JSON เพื่อสื่อสารกับหน้าเว็บ
- **HX711 (โดย Bogdan Necula):** สำหรับสื่อสารและแปลงสัญญาณจากโหลดเซลล์ (Loadcell) เพื่ออ่านค่าน้ำหนัก
- **PubSubClient (โดย Nick O'Leary):** สำหรับเชื่อมต่อและรับส่งข้อมูลผ่านโปรโตคอล MQTT กับ HiveMQ
- **RTC (โดย Makuna):** สำหรับสื่อสารและจัดการเวลาผ่านโมดูลนาฬิกา RTC DS1302 (ทำงานร่วมกับไลบรารี ThreeWire)
- **ไลบรารีพื้นฐานของระบบ (Built-in):** WiFi, WebServer, DNSServer, SPIFFS และ Preferences

### 8.2 โมดูลเสริมสำหรับ Node.js Backend (ติดตั้งผ่าน NPM)
โมดูลเหล่านี้ระบุอยู่ในไฟล์ package.json ติดตั้งด้วยคำสั่ง 
pm install:
- **express:** สำหรับสร้างโครงสร้างพื้นฐานของ Web Server และ API
- **socket.io:** สำหรับการส่งข้อมูลแบบเรียลไทม์ (Real-time Communication) ระหว่างเซิร์ฟเวอร์และหน้าเว็บ
- **mqtt:** สำหรับให้ฝั่งเซิร์ฟเวอร์เชื่อมต่อและรับส่งข้อมูลกับ HiveMQ Broker
- **@vercel/postgres:** สำหรับเชื่อมต่อและจัดการคำสั่ง SQL กับฐานข้อมูล Neon
- **dotenv:** สำหรับจัดการตัวแปรแวดล้อม (Environment Variables) เพื่อปกป้องข้อมูลสำคัญ
