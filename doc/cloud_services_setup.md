# ภาคผนวก ง: การสมัครและตั้งค่าบริการคลาวด์เซอร์วิส (Cloud Services)

เอกสารฉบับนี้จัดทำขึ้นเพื่อใช้ประกอบโครงงาน อธิบายถึงขั้นตอนการสมัครและการตั้งค่าบริการคลาวด์ต่างๆ ที่จำเป็นสำหรับระบบเครื่องให้อาหารปลาอัตโนมัติ ซึ่งประกอบไปด้วยระบบจัดการซอร์สโค้ด (GitHub), ตัวกลางสื่อสารข้อมูล (HiveMQ), และผู้ให้บริการโฮสต์เว็บไซต์ (Vercel)

## 1. การสมัครและตั้งค่าใช้งาน GitHub

GitHub เป็นระบบจัดการเวอร์ชันโค้ด (Version Control) และเป็นศูนย์กลางสำหรับจัดเก็บซอร์สโค้ดของโครงงาน เพื่อเชื่อมต่อไปยังบริการ Vercel

1. **การสมัครสมาชิก:**
   - เข้าสู่เว็บไซต์ [https://github.com/](https://github.com/)
   - คลิกปุ่ม **Sign up** และกรอกอีเมล รหัสผ่าน รวมถึงชื่อผู้ใช้งาน (Username) ตามขั้นตอน
2. **การติดตั้ง Git ลงในเครื่องคอมพิวเตอร์:**
   - ดาวน์โหลดโปรแกรม Git จาก [https://git-scm.com/](https://git-scm.com/) และดำเนินการติดตั้ง
3. **การสร้างพื้นที่จัดเก็บ (Repository):**
   - เมื่อเข้าสู่ระบบ GitHub ให้คลิกปุ่ม **New** เพื่อสร้าง Repository ใหม่
   - ตั้งชื่อโปรเจกต์ (เช่น eeder_project) เลือกระดับความเป็นส่วนตัว (Public หรือ Private) และคลิก **Create repository**
4. **การนำโค้ดขึ้น GitHub ผ่าน VS Code:**
   - ในโปรแกรม VS Code แถบด้านซ้ายมือ ให้เลือกเมนู Source Control (ไอคอนรูปกิ่งไม้)
   - กดปุ่ม **Publish Branch** เพื่ออัปโหลดโค้ดของโปรเจกต์จากเครื่องคอมพิวเตอร์ขึ้นสู่ GitHub

## 2. การสมัครและตั้งค่า HiveMQ (MQTT Broker)

HiveMQ ทำหน้าที่เป็นตัวกลาง (Broker) ในการรับส่งข้อมูลผ่านโปรโตคอล MQTT ระหว่างบอร์ด ESP32, หน้าเว็บแอปพลิเคชัน และเซิร์ฟเวอร์ฐานข้อมูล

1. **การสมัครสมาชิกและสร้าง Cluster:**
   - เข้าสู่เว็บไซต์ [https://console.hivemq.cloud/](https://console.hivemq.cloud/) และทำการสมัครสมาชิก (สามารถใช้บัญชี GitHub ล็อกอินได้)
   - เลือกแผนบริการแบบ **Serverless (Free)**
   - ระบบจะสร้าง Cluster ให้อัตโนมัติ ให้คลิกเข้าไปที่ Cluster นั้นเพื่อดูรายละเอียด
2. **การตั้งค่าความปลอดภัย (Credentials):**
   - ในเมนู **Access Management** ให้สร้างผู้ใช้งานโดยกำหนด Username และ Password (ตัวอย่างเช่น 	eerapat / Teerapat99)
   - นำข้อมูลเหล่านี้ไปใส่ในไฟล์ตั้งค่าของ ESP32 และ Node.js
3. **การรับที่อยู่เซิร์ฟเวอร์ (Broker URL):**
   - ในหน้า Overview ให้คัดลอก **Cluster URL** (เช่น xxxx.s1.eu.hivemq.cloud)
   - พอร์ตสำหรับการสื่อสารของอุปกรณ์ (ESP32) คือ **8883 (TLS)**
   - พอร์ตสำหรับการสื่อสารของหน้าเว็บ (WebSocket) คือ **8884 (WSS)**

## 3. การใช้งาน Vercel สำหรับให้บริการหน้าเว็บไซต์ (Frontend Hosting)

Vercel เป็นบริการสำหรับฝากไฟล์และรันหน้าเว็บไซต์ (Hosting) โดยมีความสามารถในการดึงโค้ดจาก GitHub มาอัปเดตและแสดงผลแบบอัตโนมัติ (Continuous Deployment)

1. **การสมัครสมาชิก:**
   - เข้าสู่เว็บไซต์ [https://vercel.com/](https://vercel.com/)
   - คลิก **Sign Up** และเลือกสมัครผ่านบัญชี **GitHub** เพื่อให้ระบบสามารถดึงโค้ดได้โดยตรง
2. **การนำเข้าโปรเจกต์ (Import Project):**
   - เมื่อเข้าสู่ Dashboard ให้คลิกปุ่ม **Add New...** และเลือก **Project**
   - ระบบจะแสดงรายการ Repository จาก GitHub ที่เชื่อมต่อไว้ ให้ค้นหาโปรเจกต์ eeder_project แล้วคลิก **Import**
3. **การตั้งค่าโปรเจกต์:**
   - ในส่วนของการตั้งค่า Framework Preset ให้ปล่อยเป็น **Other** (หรือตามที่ Vercel ตรวจพบ)
   - เนื่องจากหน้าเว็บของเราอยู่ในโฟลเดอร์ web (หรือการตั้งค่าโฟลเดอร์ตามลำดับของโปรเจกต์) ให้ระบุ Root Directory หรือตั้งค่าคำสั่ง Build ให้ตรงกับโครงสร้างโครงงาน
4. **การเผยแพร่เว็บไซต์ (Deploy):**
   - คลิกปุ่ม **Deploy** ระบบจะใช้เวลาสักครู่ในการประมวลผล
   - เมื่อเสร็จสิ้น Vercel จะสร้าง URL สำหรับเข้าใช้งานเว็บไซต์ (เช่น https://feeder-project.vercel.app/) ซึ่งสามารถนำลิงก์นี้ไปใช้งานผ่านสมาร์ตโฟนหรือคอมพิวเตอร์เครื่องใดก็ได้
