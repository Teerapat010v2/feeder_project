# ภาคผนวก ค: ขั้นตอนการติดตั้งโปรแกรมที่เกี่ยวข้อง

เอกสารฉบับนี้อธิบายขั้นตอนการติดตั้งโปรแกรมที่จำเป็นสำหรับการพัฒนาและอัปโหลดโค้ดลงบอร์ด ESP32 โดยโปรเจกต์นี้เลือกใช้ **Visual Studio Code (VS Code)** ร่วมกับส่วนขยาย **PlatformIO** แทนการใช้ Arduino IDE แบบดั้งเดิม เนื่องจาก PlatformIO มีระบบจัดการไลบรารีที่เสถียรกว่า และสามารถอัปโหลดไฟล์หน้าเว็บ (HTML, CSS, JS) เข้าสู่หน่วยความจำ (SPIFFS) ของ ESP32 ได้อย่างง่ายดาย

## 1. การติดตั้ง Visual Studio Code (VS Code)

Visual Studio Code เป็นโปรแกรม Text Editor ฟรีจาก Microsoft ที่รองรับการเขียนโปรแกรมหลากหลายภาษา

1. ไปที่เว็บไซต์ทางการของ VS Code: [https://code.visualstudio.com/](https://code.visualstudio.com/)
2. คลิกปุ่ม **Download for Windows** (หรือเลือกระบบปฏิบัติการที่คุณใช้งาน)
3. เมื่อดาวน์โหลดเสร็จสิ้น ให้เปิดไฟล์ติดตั้งที่ได้ (เช่น `VSCodeUserSetup-{version}.exe`)
4. ยอมรับข้อตกลง (I accept the agreement) และคลิก Next ไปเรื่อยๆ จนถึงขั้นตอน **Select Additional Tasks**
5. **(แนะนำ)** ให้ติ๊กเลือกช่อง "Add 'Open with Code' action to Windows Explorer file context menu" และ "Add 'Open with Code' action to Windows Explorer directory context menu" เพื่อความสะดวกในการเปิดโฟลเดอร์โปรเจกต์
6. คลิก **Install** และรอจนกว่าการติดตั้งจะเสร็จสมบูรณ์

## 2. การติดตั้งส่วนขยาย PlatformIO IDE

PlatformIO เป็นส่วนขยาย (Extension) ภายใน VS Code ที่เปลี่ยน Editor ธรรมดาให้กลายเป็นเครื่องมือสำหรับพัฒนาไมโครคอนโทรลเลอร์ (Microcontroller Development Environment) แบบเต็มรูปแบบ

1. เปิดโปรแกรม **Visual Studio Code**
2. คลิกที่ไอคอน **Extensions** (รูปบล็อกสี่เหลี่ยมต่อกัน) ที่แถบเมนูด้านซ้ายมือ (หรือกดปุ่มลัด `Ctrl + Shift + X`)
3. ในช่องค้นหา พิมพ์คำว่า **PlatformIO IDE**
4. คลิกปุ่ม **Install** ที่ส่วนขยาย PlatformIO IDE (สังเกตไอคอนรูปหัวมดเอเลี่ยน)
5. **รออย่างใจเย็น:** การติดตั้ง PlatformIO อาจใช้เวลา 3-10 นาที เนื่องจากระบบจำเป็นต้องดาวน์โหลดเครื่องมือเบื้องหลัง (Core Tools, Python, C++ Compilers) โปรดสังเกตที่มุมขวาล่างของ VS Code จะมีข้อความแสดงสถานะการดาวน์โหลดและการติดตั้ง
6. เมื่อติดตั้งเสร็จสมบูรณ์ VS Code จะแสดงข้อความแจ้งเตือนให้ทำการ **Reload Window** ให้คลิกปุ่ม Reload หรือทำการปิด-เปิด VS Code ใหม่อีกครั้ง

## 3. การใช้งาน PlatformIO ร่วมกับโปรเจกต์ (ปูพื้นฐาน)

หลังจากติดตั้ง PlatformIO เสร็จสิ้น เมื่อคุณเปิดโฟลเดอร์โปรเจกต์ (โฟลเดอร์ `esp32/fish_feeder`) ที่มีไฟล์ `platformio.ini` อยู่ PlatformIO จะรับรู้โดยอัตโนมัติว่านี่คือโปรเจกต์ของมัน

### ปุ่มเครื่องมือที่สำคัญ (แถบด้านล่างของ VS Code)

หลังจากโหลดโปรเจกต์เสร็จ คุณจะเห็นไอคอนเครื่องมือของ PlatformIO ที่แถบสีน้ำเงินด้านล่าง (Status Bar):

*   **✓ (Build):** ใช้สำหรับคอมไพล์โค้ด (ตรวจสอบว่าโค้ดมีข้อผิดพลาดหรือไม่ โดยที่ยังไม่ได้อัปโหลดลงบอร์ด)
*   **→ (Upload):** ใช้สำหรับคอมไพล์โค้ดและอัปโหลดลงบอร์ด ESP32
*   **🗑️ (Clean):** ใช้ลบไฟล์คอมไพล์เก่าทิ้ง เคลียร์แคช (มักใช้เมื่อโค้ดรวนหรือเปลี่ยนเวอร์ชันไลบรารี)
*   **🔌 (Serial Monitor):** ใช้เปิดหน้าจอเพื่อดูข้อความ (Log) ที่บอร์ด ESP32 ส่งกลับมา (เช่น ดู IP Address, ตรวจสอบสถานะการทำงาน)

### การติดตั้งไลบรารีอัตโนมัติ (Library Dependency Management)

ข้อดีที่สุดอย่างหนึ่งของ PlatformIO คือ **คุณไม่จำเป็นต้องไปหาดาวน์โหลดไฟล์ ZIP ไลบรารีมาติดตั้งเอง** เหมือนใน Arduino IDE 

เพียงแค่ระบุชื่อไลบรารีไว้ในไฟล์ `platformio.ini` (ซึ่งในโปรเจกต์นี้เขียนเตรียมไว้ให้หมดแล้ว) ทันทีที่คุณกดปุ่ม Build (✓) หรือ Upload (→) PlatformIO จะไปดาวน์โหลดไลบรารีที่จำเป็นทั้งหมดมาติดตั้งในโฟลเดอร์โปรเจกต์ของคุณแบบอัตโนมัติ

## 4. การอัปโหลดไฟล์หน้าเว็บลงหน่วยความจำ SPIFFS

โปรเจกต์นี้มีหน้าเว็บสำหรับควบคุมแบบ Offline ซึ่งไฟล์ HTML, CSS, JS และรูปภาพต่างๆ จะถูกเก็บไว้ในโฟลเดอร์ชื่อ `data` และต้องถูกอัปโหลดเข้าไปเก็บในชิปหน่วยความจำ (SPIFFS) ของ ESP32

1. ในหน้าต่าง VS Code ให้คลิกที่ไอคอน **หัวมดเอเลี่ยน (PlatformIO)** ที่แถบด้านซ้ายมือสุด
2. ในแผง PROJECT TASKS ให้คลิกขยายเมนู **env:esp32dev**
3. คลิกขยายเมนูย่อย **Platform**
4. คลิกที่คำสั่ง **Build Filesystem Image** (ระบบจะทำการบีบอัดและเตรียมไฟล์ในโฟลเดอร์ data)
5. เสียบสาย USB ระหว่างคอมพิวเตอร์และบอร์ด ESP32
6. คลิกที่คำสั่ง **Upload Filesystem Image** (ระบบจะทำการอัปโหลดไฟล์หน้าเว็บลงไปในบอร์ด)

*(หมายเหตุ: ต้องทำการอัปโหลดทั้งตัวโค้ดปกติ [ปุ่ม → ด้านล่าง] และ Upload Filesystem Image หน้าเว็บระบบถึงจะทำงานได้สมบูรณ์)*
